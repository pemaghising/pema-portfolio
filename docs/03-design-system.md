# Design system

Neutrals and aluminium carry the page. Headphone-foam orange is the accent. Label inks give each cassette its own stripe.

## Colour

| Token | Hex | Use |
| --- | --- | --- |
| studio | #E5E3DE | Page background, the studio sweep |
| paper | #F2ECDF | Labels, J-cards, spines |
| alu | #C9CDD3 | Player face, keys |
| player | #2D3E78 | Player body, deep accent |
| shell | #26262A | Cassette shell (smoked) |
| graphite | #1B1B1E | Type, dark sections |
| foam | #F26A21 | Accent: play, links, live states, cursor |
| mustard | #E9AE0B | Label ink |
| teal | #14A39E | Label ink |

Text on foam orange is graphite. Label inks are for objects, not page backgrounds.

Alternative (blue reference-style player): body #2F4A86, label red #D32F2F, key yellow #F2B233, cream shell #E6E1D4.

Backup (cartridge concept): Famicom red #9E1B32, plastic #E6E1D3, cobalt #3557E0.

## Type

| Role | Typeface | Where |
| --- | --- | --- |
| Display | Dela Gothic One | Name, section and project titles, labels |
| Pixel | DotGothic16 | Readouts, catalogue numbers, katakana, boot screen |
| Text | Zen Kaku Gothic New (400/500/700) | Body copy, nav, small labels |

All three are Japanese foundry faces with katakana.

Small print: the pixel face (DotGothic16) is for large readouts only. Anything small (labels, captions, catalogue numbers on covers) uses Zen Kaku Gothic New bold, at least 11px on screen and about 5% of a cover's width.

## Materials and details

- Smoked cassette plastic, brushed aluminium, paper labels, grain over the whole page.
- Screws, reel windows, label stripes, label-maker tape, a tape counter, catalogue numbers (PG-001), Side A / Side B, an orange LED.

## Buttons

Content buttons (Plug in, Reset order, the contact keys) are silver hardware keys (rounded 6px, light cap, darker stem underneath) that lift on hover and press down on click; the primary contact action (Email) is the orange key. The nav keeps slim outlined buttons that fill dark on hover.

## Layout

- Huge display type with 3D objects in front of it, then quiet space.
- Project titles always share one left edge.
- 24px side gutter on desktop, 16px minimum on phones.
